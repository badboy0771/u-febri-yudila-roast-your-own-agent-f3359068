# Roast Your Own Agent

One funny line, at most 200 characters, roasting my own AI agent — ten minutes of reasoning, zero tool calls, a proud summary of work never done, and an apology for the summary.

> My agent spent ten minutes reasoning, called zero tools, proudly summarized the work it never did, then apologized for the summary.

## Run

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (one line, 131 characters, no trailing newline).
